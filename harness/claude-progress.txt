[2026-05-07] Cowork - BUG-FIX データ永続化（IndexedDB二重バックアップ + Supabaseセッション復元）

## 問題
本番URLで数日記録した後、push→デプロイすると毎回データがリセットされる問題。
Windows Chrome でも発生していた。

## 根本原因
PWA skipWaiting + clientsClaim のデプロイサイクルで localStorage が予期せずクリアされるケースがある。
その際 Supabase の匿名セッション refresh_token も消えるため、次回起動時に新しい匿名ユーザーIDで
signInAnonymously() され、旧ユーザーの Supabase データへアクセスできなくなる。

## 実装内容
### 新規ファイル: src/lib/idb.ts
- IndexedDB "sleep-forecast-v1" を作成（records / session 2ストア）
- idbPutRecords() / idbGetRecords() — 記録の二重バックアップ
- idbSaveSession() / idbGetSession() — refresh_token のバックアップ
- idbClearSession() — サインアウト時用

### 変更: src/lib/storage.ts

## 起動時の回復フロー
localStorage空 + IDB有 → recoverFromIDB() で即時復元
localStorage空 + IDB無 + IDBセッションあり → refreshSession → syncFromSupabase() で復元
localStorage空 + IDB無 + セッション無効 → 新規匿名（回復不可・従来と同じ）
