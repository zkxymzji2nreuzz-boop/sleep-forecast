# SleepForecast SEO記事 禁止ワード・推奨表現リファレンス

このドキュメントは、記事執筆・リライト時に即座に参照できる「使ってはダメな表現」と「代わりに使うべき表現」の一覧です。

---

## 1. 医学的断定表現（最優先で削除）

### ❌ 絶対禁止

| 禁止ワード | 理由 | ✅ 推奨表現 |
|---|---|---|
| 「〜ことが証明されている」 | 医学的断定のニュアンスが強い。すべての記事で誇大広告に該当する可能性 | 「〜という報告があります」「複数の研究で指摘されています」 |
| 「〜という医学的事実」 | 事実という言葉が医学的専門性を標榜しすぎる | 「〜という医学的な見方もあります」「多くの医学者が指摘する〜」 |
| 「〜に効果がある」（医薬品的表現） | 薬機法違反のリスク（医療用語「効果」の乱用） | 「〜に関連があるとされている」「〜を試した人は〜と言う」 |
| 「〜を治す」「〜を治療する」 | 医療行為の標榜 | 「〜をサポートする」「〜に向き合う」「〜を改善する可能性がある」 |
| 「〜すると確実に〜になる」 | 絶対的な因果関係を示唆 | 「〜することで〜なりやすい」「可能性がある」 |
| 「科学的に証明された」 | 証明という言葉の使い過ぎ | 「科学的な観点から〜」「研究で示唆されている」 |
| 「医学的根拠により〜」 | 医学的権威を背景にした断定 | 「医学的な知見としては〜」「複数の医学論文では〜」 |

## 2. 受身・他人事的表現（段落ごとに監視）

### ❌ 報道記事的・責任逃避的な表現

| 禁止表現パターン | 理由 | ✅ 推奨表現への変更例 |
|---|---|---|
| 「〜であることが知られています」を 2 回以上 | 受身が強すぎて、ブログの「一次情報」感が失われる | 「多くの人が経験している」「医学的には〜という見方もあります」 |
| 「〜という説があります」を 3 回以上 | 他人事・曖昧感が強くなる | 「個人的には〜」「私の観察では〜」「実際に試した人の話では〜」 |
| 「〜されている」「〜とされている」を 4 回以上 | 能動性の欠如。記事が『報告書』のように見える | 「私たちは〜」「多くの研究者が指摘する〜」「実際に効果を感じる人も〜」 |
| 「科学者によると」「専門家の意見では」で始まる文が 3 行以上連続 | ブロガー個人の声が消える | 各セクションの最初に「ただし私の場合は〜」「個人的な観察では〜」を挟む |
| 「〜という情報もあります」（曖昧さの言い逃れ） | 「情報」という言葉の濫用で、根拠が不透明に見える | 「〜という研究結果もあります」「実際に効果を感じた人もいます」 |

## 3. 抽象的・一般論すぎる表現（具体化が必須）

### ❌ 読者の「何をすればいいの？」に答えていない表現

| 抽象的な表現 | 問題点 | ✅ 具体化された表現 |
|---|---|---|
| 「睡眠は大切です」 | 当たり前。行動につながらない | 「朝6時に起きる営業職の私が、就寝時刻を23時に固定したら、朝の目覚めが明らかに違った」 |
| 「ストレスを減らしましょう」 | 「どうやって？」に答えていない | 「朝日を浴びることで、ストレスホルモン『コルチゾール』が低下するという話を読んで、1週間試してみたら、確かに落ち着きが出た気がします」 |
| 「健康的な生活を心がけることが重要です」 | 最優先度が不明。読者は迷う | 「気圧が低い日は、いくら頑張ってもからだが反応するので、その日は『健康的に頑張る』のではなく『早めに休む』という選択をしている」 |
| 「良好な睡眠環境が必要です」 | 『良好』の基準が不明 | 「私の場合、気圧が低い夜は気温18〜20度、遮光カーテン完全閉鎖、ノイズキャンセリングイヤホンなしの環境がちょうど良い」 |
| 「定期的な運動が推奨されます」 | 「どの程度の頻度か」「自分に適用できるか」不明 | 「週3回の45分ウォーキングを3ヶ月続けたら、低気圧の日の倦怠感が軽くなった。ただ、毎日は無理なので、週3回のペースが自分には最適」 |

## 4. カタカナ乱用・専門用語の濫用

### ❌ 「ブログのくせに専門家ぶってる」に見える表現

| カタカナ乱用パターン | 理由 | ✅ 代替え表現 |
|---|---|---|
| 「コルチゾールの上昇により REM 睡眠が阻害される」 | 医学論文のような難しさ。読者は置き去り | 「ストレスホルモンが増えると、浅い眠りが増えやすくなる」「ストレスホルモン『コルチゾール』が〜」と1回目に説明を付ける |
| 「サーカディアン・リズムが乱れると〜」を 3 回以上 | 用語疲労。日本語に訳すべき | 初回：「体内時計（サーカディアン・リズム）」。2回目以降：「体内時計」のみ |
| 「交感神経と副交感神経の SNS バランス」 | SNS（Social Network Service）との混同リスク。医学用語 SNS（Sympathetic Nervous System）の乱用 | 「交感神経と副交感神経のバランス」。医学的には「自律神経バランス」 |
| 「メラトニン分泌の抑制」を複数回 | 医学用語が多すぎて、記事が『ハウツー』ではなく『論文抄録』に見える | 「眠気を起こすホルモン『メラトニン』が出るのが遅くなる」と日常語で説明 |
| 「セロトニン・ドーパミン・ノルアドレナリンの三角関係」 | 『三角関係』という造語で、医学的正確性が下がる | 「複数の神経伝達物質が関係して」と簡潔に |
| 「概日リズム」「体温リズム」「皮膚体温」 | 日本語で十分に説明できる内容を、わざわざ学術用語で | 「1日の体温の周期」「肌の表面温度」 |

#### カタカナ用語を避けられない場合のルール
```
【初出時の書き方】
「月齢（つきれい）とは〜」
「サーカディアン・リズム（体内時計）とは〜」

【2 回目以降】
カタカナは削除し、日本語のみで記述

【例】
❌ 「サーカディアン・リズムが乱れると、メラトニン分泌が...」（同じ文に 2 つのカタカナ）
✅ 「体内時計（サーカディアン・リズム）が乱れると、眠気ホルモンが...」
```

## 5. 曖昧な数値・単位表現

### ❌ 「ほぼ、だいたい、かなり」が多い

| 曖昧な数値表現 | 理由 | ✅ 正確な表現 |
|---|---|---|
| 「多くの研究」（件数不明） | 何件？10件？100件？読者は判断できない | 「複数の研究」「特に2013年のバーゼル大学の研究では」 |
| 「ほとんどの人」 | パーセンテージが不明。医学的には不正確 | 「私の周囲の営業職5人のうち4人が〜」「研究では約60%の被験者が〜」 |
| 「かなりの確率で」 | 数値化されていない。信頼度低 | 「試験実施者の約70%が効果を報告している」 |
| 「약〜」「だいたい〜」（科学的コンテキストで） | 科学論文的にはご法度。ブログでも信頼度低下 | 数値が不明な場合は「私の個人的な感覚では」と主観を明示 |
| 「わずかに」「ほんのちょっと」 | 量的客観性がない | 「月齢の影響がある場合、気圧の影響よりは小さかった」と比較形で示す |

#### 数値がない場合の書き方
```
❌ 「多くの人が低気圧で眠くなる」
✅ 「低気圧で眠くなると報告する人が多い。実際、私の周囲の営業職5人中4人がそう言う」

❌ 「だいたい、このくらいの気圧低下があれば〜」
✅ 「1日で気圧が5hPa以上低下した時期に、眠気が強まるパターンを私は複数回経験している」
```

## 6. やたら長い複文（読みにくさ）

### ❌ 一文が 50 字以上、かつ関係詞が 2 個以上

| 禁止パターン | 問題点 | ✅ 分割例 |
|---|---|---|
| 「気圧が下がることで血管が拡張し、その圧力が神経を刺激することで、痛みとして知覚されるというメカニズムの結果として、多くの人が頭痛を経験する傾向にあります。」 | 複雑。60字以上。読み直す必要がある | **分割版：** 「気圧が下がると、血管が広がります。」「この広がりが神経を刺激します。」「その結果、痛みになるわけです。」 |
| 「睡眠と気象の関係を把握するためには、毎日の睡眠の質と気象データを併せて記録しておくことが有効であるということを、複数の研究が示唆しているだけでなく、実際に私自身の 3 ヶ月間の個人的な実験によっても確認されています。」 | 複雑。医学用語と私的体験が混在。100字超 | **分割版：** 「睡眠と気象の関係を知りたい？」「毎日の睡眠データと気象を記録するといい。」「複数の研究でも推奨されている。」「私も3ヶ月試してみた。」「その結果、確かに関連性が見えた。」 |

#### 長い複文を避けるルール
```
【ONE SENTENCE = ONE IDEA】
1 つの文には 1 つの意味・情報のみ

【目安】
- 1 文 = 40 字以下
- 句読点は最大 1 個（「、」または「。」のどちらか）
- 「で」「が」「や」「から」「けれど」のような接続詞は 1 回のみ

【改善例】
❌ 「低気圧が来る時期に、自律神経が乱れやすくなり、その結果として、睡眠の質が低下する傾向にあります。」
✅ 「低気圧が来ると、自律神経が乱れます。」「その結果、睡眠の質が低下しやすいんです。」
```

## 7. 医学的に必要だが配置を工夫すべき表現

### ⚠️ 使用可だが、条件あり

| 表現 | 条件 | ✅ 正しい使用例 |
|---|---|---|
| 「〜という説もあります」 | 2 回以上使う場合は、その後に「個人的には」を足す | 「潮汐リズムとの同期という説もあります。ただ、個人的には気圧の影響の方が大きく感じます」 |
| 「研究では〜」 | 出典を明示（年号・機関名） | 「2013年のバーゼル大学の研究では〜」（「研究では」だけはダメ） |
| 「医学的には」 | その後に「ただし個人差〜」と付け加える | 「医学的には朝日が体内時計をリセットすると言われます。ただし個人差もあります」 |
| 「専門家の見解では」 | その後に「一方、私は〜」と対比させる | 「専門家の見解では『寝る前のスマホは避けるべき』とのこと。一方、私の場合、スマホの操作自体がストレスレリーフになったり...」 |

## 8. AI っぽさを避けるための「人間らしい」フレーズ集

### ✅ 積極的に使うべき一人称・カジュアル表現

| 表現カテゴリ | 例 |
|---|---|
| **一人称の多様性** | 「私は〜」「私たちは〜」「自分の場合は〜」「私自身が経験したのは〜」「正直なところ〜」 |
| **正直さ・迷い** | 「判断がつきませんでした」「実は失敗もあります」「正直に言うと、効果がわかりませんでした」「わからなくなってしまいました」 |
| **驚き・気づき** | 「あ、わかる！」「実はそうなんです」「へえ、そっか」「気づいたんですよ」「目からウロコでした」 |
| **試行錯誤** | 「試してみた」「チャレンジしたら」「やってみたところ」「工夫してみた」「いろいろ試した結果」 |
| **個人差の尊重** | 「人によっては〜」「私の場合は〜だったけど、友人は〜」「万能な対策はないんですが」「全員には効かないかもしれませんが」 |
| **カジュアルな言い回し** | 「そこで〜」「つまり〜」「というのも〜」「のは〜」「んです」「ぴんときた」「なぞなぞを解く感じで」 |

#### 使い方の例
```
【段落例】
「低気圧が来るたびに眠れなくなるって、ほんと困りますよね。
そこで『気のせいじゃなくて、実際に気圧が関係しているのか』を確かめたかったんです。
3ヶ月記録してみたら、あ、確実に関連性がある。
その気づきから、『気圧予報をチェックして早めに寝る』という対策が生まれました。」

→ 一人称、試行錯誤、気づき、行動変化が自然な流れで並んでいる
```

## 9. 医学免責文の必須形式

記事末尾に必ず以下のいずれかを記載してください。

### 推奨形式（短くてカジュアル）
```
**免責事項**: 本記事は一般的な情報提供を目的としたものであり、医学的な診断・治療の代替ではありません。
症状が続く場合は、医療機関にご相談ください。
```

### 代替形式（より詳細）
```
**医学的注記**: 本サービスは医療行為・診断を目的としたものではありません。
記録は健康管理の参考としてご利用ください。
症状に不安がある場合は、医療機関にご相談ください。
```

### ❌ 使用禁止な免責文
```
「本記事の情報は医学的根拠に基づいており〜」（『根拠に基づいている』が医学的権威を標榜しすぎ）
「医学的に正しい情報を〜」（『正しい』と言い切るのは医学的断定）
```

## 10. チェックリスト（記事完成時の自己点検）

記事を書き終わったら、以下を実行してください。

### 禁止ワード削除チェック
```
□ 「〜ことが証明されている」を削除した
□ 「〜に効果がある」を「〜関連がある」に変更した
□ 「〜を治す」を「〜をサポートする」に変更した
□ 「〜されている」の受身表現を 3 回以下に削減した
□ 「医学的に断定している」表現をすべて「個人的には」「報告がある」に変更した
```

### 一次情報・人間らしさチェック
```
□ 一人称「私」が最低 5 回以上ある
□ 失敗談・試行錯誤が 1 つ以上ある（完全な成功ストーリーではない）
□ 具体的な数字・時間・商品名が 3 つ以上ある
□ 「あ、わかる」という小さなあるあるネタが複数ある
□ 医学免責文が末尾に記載されている
□ 段落が 4 行以上連続していない
□ 複文が 3 行を超えていない
```

### AI っぽさ回避チェック
```
□ 「〜とされている」「〜という見方がある」の類が 1 段落に 1 回以下
□ 敬語（です/ます体）が全体の 60% 以下（カジュアル化）
□ 専門用語が初出で説明されている
□ 文末が「〜します」で終わる文が連続していない（リズム変化）
□ 「正直」「実は」「ぴんときた」などの人間らしい言い回しがある
```

## 参考：この規則が生まれた背景

### 医学的責任
SleepForecast は健康データを扱うため、医学的な『言い過ぎ』は薬機法・景表法違反のリスクがあります。
同時に、『言い過ぎない』ことで信頼度が上がる（過度な誇張より、正直さが信頼を呼ぶ）という効果も期待できます。

### SEO効果
- 一次情報・体験談が豊富な記事は「E-E-A-T（Experience, Expertise, Authoritativeness, Trustworthiness）」スコアが高まる
- Google は AI 生成コンテンツより「人間が実際に試した」記事を上位評価する傾向
- あるあるネタや失敗談は、滞在時間・シェア率が上がる

### ユーザー体験
- 『絶対効く』と言わないことで、個人差を尊重した記事に見える
- 失敗談があると、読者は『この人も悩んでた』と親近感を持つ
- 具体例が多いと、実装のイメージがわきやすく、アプリをダウンロード・使用する動機が上がる
