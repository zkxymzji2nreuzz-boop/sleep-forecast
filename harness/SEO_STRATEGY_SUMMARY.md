**作成日**: 2026-04-10  
**対象**: 現在10本の記事のリライト + 将来記事の執筆ガイドライン化

---

## 戦略の全体像

SleepForecast は「睡眠 × 気象」というニッチ領域の SEO メディア戦略を取っています。  
現在のコンテンツは「医学的に正確で網羅的な説明」中心になっており、**AI 生成記事に見えやすく、読者の心理的距離感が遠い**という課題があります。

この戦略は、**稼いでいる日本人ブロガー（マナブ、ヒトデ、クロネコ屋）の『一次情報・体験談ベース』の手法に倣い、記事を『人間らしく、親近感のあるコンテンツ』に転換するためのロードマップです。

## 核となる 5 つの原則

### 1. **一次情報優位性**
```
❌ 「多くの研究で示唆されている」
✅ 「朝 6 時 15 分に起きる営業職の私が、
   前夜の気圧予報をチェックして 23 時に寝た日は、
   朝の頭重感が 40% 軽かった感覚があります」
```
→ 医学的知見は「背景」に留め、個人の実感を「前景」に。

### 2. **失敗談の組み込み**
```
すべての記事に最低 1 つの失敗談を含める
- スマートウォッチ 65,000 円で失敗
- GABA サプリ月額 3,000 円で判断がつかず
- 瞑想アプリで逆効果

→ 「この人も同じ悩みを持ってた」という親近感が信頼を呼ぶ
```

### 3. **あるあるネタの多層構造**
```
導入：「月曜朝に限って頭が重い」（個人のあるある）
  ↓
中盤：「同僚の営業職も同じことを言ってた」（複数人の共通体験）
  ↓
セグメント化：「営業職はこう、エンジニアはこう」（ペルソナ別）
  ↓
記事に滞在時間が伸び、シェア・フォロー率が上がる
```

### 4. **医学的責任と信頼のバランス**
```
絶対禁止：「〜に効果がある」「〜を治す」
推奨：「〜関連があるとされている」
    「個人的には〜」
    「試した人の話では〜」
医学免責：記事末尾に必ず記載

→ 過度な誇張を避けることで、むしろ信頼度が上がる
  （Trustworthiness スコアが高まる = Google 評価向上）
```

### 5. **ペルソナ田中さんの物語化**
```
各記事内で、ペルソナ「田中由紀恵（42 歳、営業職）」の
- セリフ
- モノローグ
- 試行錯誤の流れ

を度々挿入することで、記事が『個人のストーリー』に見える

→ 特定の読者（30～50 代の営業職女性）が
  「あ、これ私のために書かれた記事だ」と感じる
```

## 期待される効果

### SEO 効果
- **E-E-A-T スコア向上**
  - Experience（個人の実経験）が豊富
  - Expertise（医学知見）も並行
  - Authoritativeness（ペルソナによる一貫性）
  - Trustworthiness（誇張なし、失敗談で信頼構築）

- **検索ランキング向上**（特に「気象病」「低気圧 睡眠」「月齢 眠気」など）

- **滞在時間・シェア率向上**
  - あるあるネタが増える → 「あ、わかる」が複数回発生 → 記事の最後まで読まれる
  - 失敗談があると SNS シェア率が上がる傾向

### ユーザー体験
- **親近感向上**
  - 「これは AI が書いた記事」ではなく「同じ悩みを持つ人が書いた記事」に見える
  - ペルソナ田中さんのストーリーに感情移入
  
- **行動転換**
  - 「気象病かも」と思う読者 → SleepForecast ダウンロード
  - 記録を始めてから「あ、本当に気圧が関係してる」と気づく
  - 継続利用率向上

### ビジネス効果
- **AdSense 収益向上**（滞在時間 × PV が増加）
- **睡眠系アフィリエイト転換率向上**
  - 記事内で失敗した商品（スマートウォッチ、サプリ）への記載 → 「代わりにこの方法がいい」という導動線
- **ブランド信頼度向上**
  - 「医療免責を丁寧に書く企業」という認識
  - Google の「医療系コンテンツ」審査通過の可能性向上

## 注意事項

### ❌ してはいけないこと
- 医学的責任を軽視する（必ず医学免責を記載）
- 失敗談で「この製品は悪い」と断定的に書く（「自分には合わなかった」にとどめる）
- ペルソナ田中さんのセリフをやりすぎ（不自然に見える）
- 新しい医学用語を入れる時に説明を省く

### ✅ 心がけること
- 「正直さが信頼を呼ぶ」というマインドセット
- 読者層（30～50 代、気象病自覚層）の目線に立つ
- 毎記事リリース前に「自分だったら読みたい記事か」を問う
- Google のヘルスケア・セキュリティポリシーをたえず意識
