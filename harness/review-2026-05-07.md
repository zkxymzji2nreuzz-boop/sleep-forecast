## 優先度付き修正リスト

### 🔴 P0 — CRITICAL（法的・医療リスク / 今すぐ対応）

#### C-01: PredictionCard 免責テキストのコントラスト不足（3エージェント一致）
- **問題**: `text-white/70` がグラデーション背景（赤〜オレンジ、黄〜アンバー）上に重なり、WCAG AA 4.5:1 を大幅下回る。法的に必須の医療免責が実質読めない
- **ファイル**: `src/components/PredictionCard.tsx` L242–245
- **修正案**:
  ```tsx
  // Before
  <p className="text-xs text-white/70 leading-relaxed mt-4">
  // After
  <p className="text-xs text-white leading-relaxed mt-4 bg-black/30 backdrop-blur-sm rounded-md px-3 py-2">
  ```

#### C-02: プライバシーポリシーの「Anthropic」言及を削除（SEO Agent）
- **問題**: `privacy/page.tsx` に Anthropic のポリシーへの言及があり、運営主体の混乱を招く。AdSense審査でマイナス
- **ファイル**: `src/app/privacy/page.tsx` L155–157
- **修正案**: 当該文を「本サービスは、広告コンテンツが記事の中立性を損なうことのないよう、編集コンテンツと広告枠を明確に区別して配信しています。」に置換

#### C-03: 利用規約のiOSアプリ・サブスク条項整合性確認（SEO Agent）
- **問題**: 利用規約 L21・L49 に「iOS向けアプリ」「¥300/月」記載があるが、iOSアプリ未リリースなら景表法リスク
- **ファイル**: `src/app/terms/page.tsx`
- **修正案**: 「※iOSアプリは現在準備中です」注記追加、または第4条（サブスクリプション）を一時コメントアウト

### 🟠 P1 — HIGH（UX・A11y・デザイン品質に直結 / 今週中）

#### H-01: 予測スコアの方向性が曖昧（2エージェント一致）
- **問題**: 「1.0/5.0 + かなり眠い」の表記が「眠気が強い=寝つきが良い？」とも読めて誤解を招く。1=悪い、5=良いの方向が一目でわからない
- **ファイル**: `src/components/PredictionCard.tsx`
- **修正案**: スコア表示横に「？」ツールチップ「5に近いほど良眠予測」を追加。またはラベルを「睡眠スコア 1.0 / 5.0」から「眠れない予報 🚨」のように方向が自明なコピーに変更

#### H-02: 実績バッジ 達成/未達成 の視覚的差別化強化（UI Agent）
- **問題**: 達成済み薄紫タグ vs 未達成グレー枠の色差が小さく、ゲーミフィケーション効果が半減
- **ファイル**: `src/components/AchievementsSection.tsx`
- **修正案**:
  ```css
  /* 達成済み: primary グラデ + 影 */
  .badge-achieved { background: linear-gradient(135deg, #6B5BA8, #A599D6); color: white; box-shadow: 0 2px 8px rgba(107,91,168,0.3); }
  /* 未達成: grayscale 0.7 + opacity 0.55 */
  .badge-locked { filter: grayscale(0.7) opacity(0.55); }
  ```

#### H-03: フォームバリデーション失敗時の自動フォーカス + aria-invalid（Tech Agent）
- **問題**: 送信時エラーメッセージ表示はあるがフォーカス移動なし。`aria-invalid` 属性も未付与でスクリーンリーダーに伝わらない
- **ファイル**: `src/components/RecordForm.tsx` L242–250
- **修正案**: `validate()` にエラー要素への `scrollIntoView + focus()` 追加。各 input に `aria-invalid={!!errors[k]}` を付与

#### H-04: エラーテキスト色をテーマ対応に（Tech Agent）
- **問題**: `text-[#f87171]` ハードコードがライトモードで背景白に対し約 3.4:1（AA 4.5 未満）
- **ファイル**: `src/components/RecordForm.tsx` L702, 716, 727 など
- **修正案**: `text-rose-600 dark:text-rose-400` に変更

#### H-05: PredictionCard カラーをデザインシステムに統合（UI Agent）
- **問題**: 赤〜オレンジグラデが Twilight Lavender のラベンダー基調から完全に浮き、「個人開発感」を生む
- **ファイル**: `src/components/PredictionCard.tsx` `getScoreGradient()`
- **修正案**: 彩度を 30% 落として primary (#6B5BA8) を 20–30% ブレンド
  ```tsx
  // 例: score <= 1.5 時
  "from-[oklch(58%_0.15_15)] to-[oklch(62%_0.13_40)]"
  // ダークモード別定義を追加
  ```

#### H-06: CorrelationChart に aria-describedby + sr-only データテーブル（Tech Agent）
- **問題**: `role="img" + aria-label` のみで、スクリーンリーダー利用者は相関係数・傾向を把握できない。WCAG 1.1.1 違反
- **ファイル**: `src/components/CorrelationChart.tsx` L205–214
- **修正案**: r 値と傾向の自然言語解説 + 日付×品質×気圧差の `<table className="sr-only">` を `aria-describedby` で紐付け

### 🟡 P2 — MEDIUM（品質向上 / 今月中）

#### M-01: ホームとダッシュボードのコンテンツ重複解消（UX Agent）
- **問題**: 両ページに「明日の睡眠予報」が大きく表示されており、役割分担が曖昧
- **修正案**: ホーム = 短期サマリ + CTA + 記事入口、ダッシュボード = 詳細分析専用に役割整理
- **注意**: 大規模リファクタのため別セッションで実施

#### M-02: 散布図の補足キャプション追加（UX/UI Agent）
- **問題**: 傾向線（破線）の意味が説明されず、気圧軸との関係が読みにくい
- **ファイル**: `src/components/CorrelationChart.tsx`
- **修正案**: 「気圧が下がるほど睡眠品質が低下する傾向（相関係数 r = X.XX）」キャプションを動的に表示

#### M-03: 棒グラフのグリッド線を淡く（UI Agent）
- **問題**: 「気象別平均品質」棒グラフの格子線が太く「設計図感」
- **修正案**:
  ```tsx
  grid: { color: 'rgba(107, 91, 168, 0.08)', lineWidth: 1 }
  ```

#### M-04: 気圧別カラーの医学的中立化（Tech Agent）
- **問題**: 棒グラフの「急上昇」カラーが緑（#4ade80）で「気圧上昇=良い」のミスリード
- **修正案**: 急上昇 → `#60a5fa`（青）で医学的に中立な色に変更

#### M-05: E-E-A-T強化：参考文献セクション追加（SEO Agent）
- **問題**: 健康YMYLジャンルで参考文献が無く、AdSense審査・検索順位に影響
- **修正案**: 各記事末尾に「参考文献」セクション追加（厚労省 e-ヘルスネット、日本気象学会等）

#### M-06: layout.tsx の keywords 重複削除（SEO Agent）
- **問題**: `keywords` メタタグに「気象病」が重複登録（L31, L38）
- **修正案**: 重複を削除して8個に整理

#### M-07: 手動気象入力の数値範囲バリデーション（Tech Agent）
- **問題**: 気温・湿度・気圧の範囲外値が送信でき、将来の集計を歪める可能性
- **修正案**: 気温 -50〜50°C、湿度 0〜100%、気圧 950〜1050hPa で validation 追加

#### M-08: `<textarea>` に aria-describedby で文字数カウンタを紐付け（Tech Agent）
- **ファイル**: `src/components/RecordForm.tsx` L736–741
- **修正案**: `aria-describedby="note-counter"` + カウンタに `id="note-counter"` 付与

#### M-09: ヒーロー P0 CTA に「サンプルで試す」リンク追加（SEO Agent）
- **問題**: CTA が「今日を記録する」一択で、初回ユーザーへのデモ体験導線が弱い
- **修正案**:
  ```tsx

    まずはサンプルで試してみる
  </Link>
  ```

#### M-10: 記事ページに参考文献・目次アンカーリンク追加（SEO Agent）
- 記事のURLスラッグ命名規則ドキュメント化
